# Prompt 05 — Home Page

Implement the approved single-page home experience from verified content and the design system.

Required order: editorial hero without eyebrow text; concise profile with Career Growth Grid; compact project index controlling one active preview; Experience; verified capabilities/technology section; separate Leadership section; relevant recognition; contact composer; footer.

Project preview behavior: no auto iframe. Use an approved optimized image or labeled artwork. Explicit **Expand details** toggles a fade overlay on the same image. It reveals problem, role, verified outcome, summary, stack, and allowed actions. **View live** opens only verified deployments. **Read case study** appears only for completed routes. Mobile must not depend on hover; use accessible disclosure state, focus management where needed, and reduced-motion fallback.

Keep client boundaries small. Do not add cards around every section or introduce an animation package without approval.

Run all task checks and complete a written visual QA checklist at 320px, a common modern phone width, tablet, and desktop.
