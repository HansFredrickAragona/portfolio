# Prompt 01 — Evidence Discovery and Plan

Planning only. Do not install packages or implement UI.

Inventory `project-input/` without exposing private content. Create an evidence matrix mapping each proposed public claim, timeline milestone, project field, link, image, award, experience, and resume entry to its source and publication status. Identify conflicts and stop on them.

Draft or update:

- `docs/PROJECT_BRIEF.md`
- `docs/CONTENT_MODEL.md`
- `docs/EVIDENCE_MATRIX.md`
- `memory/CONTENT_GAPS.md`
- `memory/TASKS.md`
- `memory/CURRENT_STATE.md`
- `memory/HANDOFF.md`

Build a 2–3 day critical-path plan with tasks small enough for one validated commit. Mark owner approvals, dependencies, file ownership, and acceptance criteria. Do not treat missing assets as permission to invent them.

## Approval gate 1

Present the evidence status, unresolved decisions, proposed content inventory, route/section plan, and task sequence. Stop for approval.
