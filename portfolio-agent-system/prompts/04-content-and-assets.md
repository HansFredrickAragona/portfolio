# Prompt 04 — Content and Assets

Content specialist creates typed content schemas/modules and MDX case-study drafts using only the evidence matrix. Copy approved public assets into appropriate locations; never copy the private source resume. Verify the public resume is redacted before placing it in `public/`.

Create the Career Growth Grid dataset on a fixed semester timeline. Each cell must have a source, category, concise label, accessible description, and intensity rationale. It is not a commit graph and must not imply code frequency.

Prepare project previews for Soil Scan, BaguioReadyGIS, Grammar Checker, and Resume Job Tracker. Completed projects may have case studies. Unfinished projects have honest status and no unverified actions. Generate branded abstract artwork only for missing images; label it in metadata as illustrative artwork.

Run schema/content tests, privacy scan, broken asset/link check, and build.

Present final proposed public copy, content gaps, asset manifest, redaction result, and claims requiring owner confirmation. Stop.
