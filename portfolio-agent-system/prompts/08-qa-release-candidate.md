# Prompt 08 — QA and Release Candidate

QA specialist performs a fresh review; orchestrator verifies results.

Required checks: formatting, lint, strict TypeScript, relevant automated tests, production build, accessibility, keyboard navigation, reduced motion, light/dark themes, 320px through desktop responsive behavior, project disclosures, case-study routing, resume download, contact composition and fallbacks, external links, metadata, sitemap/robots, image optimization, console errors, horizontal overflow, secrets, private content, and unverified claims.

Create `docs/QA_REPORT.md` as a text-only report with viewport, section, expected behavior, observed behavior, severity, reproduction, and resolution. Do not claim visual success from build output alone.

Release blockers include missing/placeholder core content, accessibility failures, broken contact/live links, poor mobile layout, unverified claims, secrets, or private content.

## Approval gate 8

Present pass/fail status, blockers, residual risks, and manual owner checks. Do not deploy.
